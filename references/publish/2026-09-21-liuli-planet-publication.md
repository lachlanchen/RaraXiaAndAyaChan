## Reuse Notes

The current episode is already published. These commands document the sequence,
not instructions to submit it again:

1. Upload with `lazyedit_publish.py --video "$SOURCE" --prompt-file "$CONTEXT"`
   and `--correct-subtitles --no-process --no-publish`.
2. Inspect original/polished subtitle text and timestamps. If acoustic alignment
   fails, preserve both and import a separately reviewed SRT using
   `--subtitle-file "$REVIEWED_SRT" --subtitle-language zh`.

   `--burn-subtitles --subtitle-lift-ratio 0 --portrait-blur-fill`

   Direct normal `/api/videos/ID/burn-subtitles` can reburn reviewed translation

   `--no-correct-subtitles --publish --platforms shipinhao,instagram,youtube,douyin`

   the queue-level no-process bug is fixed. Verify the ZIP video hash.
