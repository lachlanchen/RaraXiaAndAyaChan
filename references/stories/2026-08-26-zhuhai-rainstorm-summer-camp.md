# 珠海暴雨里的救援箱

珠海海边的夏令营刚集合，乌云就压过海面。雨一下大起来，远处的港珠澳大桥只剩下朦胧的轮廓。营地广播传来消息：山坡上的避雨屋断电了，十几名营员正在里面等待手电、药箱和热姜茶。

阿芽酱合上拼皮笔记本，把救援箱抱进怀里：

“我们从旧栈道过去，那里离避雨屋最近。”

啦啦侠拉紧雨衣，挡在她迎风的一侧：

“你看路，我护着箱子。”

四人刚走上湿滑的海边栈道，三台黑色机械掠夺者便从雨幕中冲出来。它们甩出抓钩，钩住救援箱，想连箱子一起拖走。

啦啦侠抱紧箱子，被拖得鞋底一路打滑。他急得喊：

“药箱可以晃，姜茶不能洒！”

阿芽酱借着护栏翻身跃起，一脚踢偏抓钩。飒飒君挥动竹子，把第二根钢索打回雨里；庄子启动脚底锚钉，抓住第三根钢索，把冲来的机械车硬生生拉停。最后一台敌机从侧面撞来，啦啦侠把救援箱交给阿芽酱，转身用肩膀撞开它。阿芽酱顺势按下栈道的防浪门，三台掠夺者一起被关在门外。

四人冒雨跑进避雨屋。庄子打开救援箱检查：

“手电、药箱、毛巾，一样没少。”

啦啦侠浑身滴水，盯着保温壶问：

“那热姜茶呢？”

阿芽酱笑着递给他一杯：

“先给最会挡雨的人。”

窗外仍是大雨，屋里亮起手电和暖灯。大家围着热姜茶坐下，夏令营重新热闹起来。

## 校对结果

- 因果链清楚：暴雨断电 -> 护送救援箱 -> 敌人抢夺 -> 四人合作反击 -> 物资抵达。
- 战斗动作具体，四位主角各有明确作用。
- 对白可以自然说出口，没有口号式解释。
- 珠海海岸、夏令营、暴雨和远处港珠澳大桥共同建立地点感。
- 结尾用热姜茶收束紧张情绪，保持温暖和可爱。
