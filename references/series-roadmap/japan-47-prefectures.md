# 日本 47 都道府县旅行清单

日本先在世界国家篇中建立总印象，再按 47 都道府县展开长期旅行。

## 北海道与东北

- [ ] 北海道：流冰、花田、函馆、札幌
- [ ] 青森：睡魔祭、苹果、奥入濑
- [ ] 岩手：平泉、三陆海岸、远野
- [ ] 宫城：松岛、仙台、海岸
- [ ] 秋田：角馆、田泽湖、雪国
- [ ] 山形：山寺、藏王、樱桃
- [ ] 福岛：会津、五色沼、只见线

## 关东

- [ ] 茨城：偕乐园、国营常陆海滨公园
- [ ] 栃木：日光、那须
- [ ] 群马：温泉、山地铁路
- [ ] 埼玉：川越、秩父
- [ ] 千叶：房总海岸、渔港、乡村铁路
- [ ] 东京：目黑、浅草、湾岸、街区生活
- [ ] 神奈川：镰仓、横滨、箱根

## 中部

- [ ] 新潟：稻田、雪国、佐渡
- [ ] 富山：立山黑部、富山湾
- [ ] 石川：金泽、能登

- [ ] 山梨：富士山、葡萄园
- [ ] 长野：阿尔卑斯、松本、雪场
