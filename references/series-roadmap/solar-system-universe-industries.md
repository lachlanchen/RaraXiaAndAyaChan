# 太阳系、宇宙与产业系列

这些系列在国家与中国地方旅行之后展开。每集仍保留一个可见目标、一个小问题、一次合作和一个令人记住的结尾。

## 太阳系路线

1. 地球轨道与太空电梯
2. 月球基地、月海与背面
3. 水星的极端昼夜
4. 金星云层与高空城市
5. 火星城市、峡谷、冰与古老河道
6. 小行星带与谷神星
7. 木星风暴与四颗伽利略卫星
8. 木卫一火山、木卫二海洋、木卫三磁场、木卫四古老冰面
9. 土星环、泰坦湖泊与土卫二喷泉
10. 天王星、海王星与它们的卫星
11. 冥王星和卡戎
12. 柯伊伯带、彗星与太阳系边缘

## 宇宙路线

1. 太阳附近的恒星与星际航行
2. 分子云与恒星诞生
3. 红巨星、白矮星与恒星晚年
4. 超新星与元素形成
5. 中子星和脉冲星
6. 黑洞的事件视界与光子球
7. 球状星团与银河系中心
8. 银河系旋臂和星际尘埃
9. 仙女座星系与星系相遇
10. 活跃星系核与类星体
11. 星系团、引力透镜与宇宙网
12. 早期宇宙、微波背景与可观测宇宙边缘

## 产业与技术路线

| 类别 | 可展开主题 | 适合的故事线 |
| --- | --- | --- |
| 农业 | 种子、温室、灌溉、采收、畜牧、智慧农场 | 从一颗种子到一顿饭 |
| 食品 | 面包、寿司、发酵、冷链、食品安全 | 找出味道或温度环节的问题 |
| 纺织 | 纤维、纺纱、染色、织造、服装 | 为伙伴制作一件有功能的新衣服 |
| 建筑 | 木构、钢结构、混凝土、模块化建筑 | 在天气变化前完成一座安全空间 |
| 矿业与材料 | 矿石、冶炼、合金、陶瓷、二维材料 | 从不起眼的材料找到关键性能 |
| 能源 | 风、光、水、储能、核能 | 为城市或基地恢复稳定能源 |
| 水与环境 | 净水、海水淡化、回收、生态修复 | 让一条河或一座社区重新运转 |
| 物流 | 港口、仓库、冷链、铁路、无人配送 | 在时间限制内送达重要物品 |
| 汽车与交通 | 电动车、电池、传感器、道路系统 | 找出车辆协作中的一个瓶颈 |
| 航空航天 | 飞机、火箭、卫星、空间站 | 完成一次真实目的明确的任务 |
| 船舶 | 造船、导航、海洋工程 | 穿过风浪完成救援或运输 |
| 机器人 | 灵巧手、移动机器人、无人机、具身智能 | 庄子和伙伴互相学习动作 |
| 芯片 | 架构、EDA、晶圆、光刻、封装、测试 | 一颗芯片从设计到点亮 |
| 电子 | 传感器、PCB、显示、相机、可穿戴设备 | LightMind 找到肉眼忽略的线索 |
| AI | 数据、训练、推理、评测、边缘 AI | 让模型通过真实任务学会判断 |
| 软件 | 操作系统、编译器、数据库、云服务、安全 | 修复一条看得见的服务链路 |
| 通信 | 光纤、无线、卫星通信、网络协议 | 让失联地点重新收到消息 |
| 生物与医药 | 自动化实验、类器官、显微成像、药物筛选 | 在 AgInTi 实验室验证一个发现 |
| 医疗器械 | 影像、手术机器人、康复设备 | 用准确操作帮助一位具体病人 |
| 光学与 AR | 镜片、光波导、显示、相机、显微镜 | 让不可见的信息变得可观察 |
| 制造 | CNC、注塑、3D 打印、装配、质量检测 | 从图纸到可以使用的产品 |
| 媒体与音乐 | 录音、动画、影视、出版、直播 | 四位伙伴组成团队完成一场作品 |
| 商业与零售 | 设计、采购、展示、支付、售后 | 把一个好产品送到真正需要的人手里 |
| 循环经济 | 维修、再制造、材料回收 | 把废弃物变成新的有用物品 |

产业集以“原料或需求 -> 关键环节 -> 小问题 -> 合作解决 -> 看得见的成果”为基本结构，让技术知识跟着故事走。
