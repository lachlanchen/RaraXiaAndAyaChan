# Xiaoyunque Default Duration Policy

For LALACHAN video generation, use these defaults unless the current request
specifies different settings:

- Duration: about 30 seconds.
- Mode: 创作 Agent / integrated-agent.
- Model: Seedance 2.0 Mini 体验版, or the cheapest visibly suitable model.
- Ratio: 4:3.
- Prompt: mainly Chinese, with no generated subtitles.

Use 沉浸式短片 when the user explicitly asks for a 15-second video or another
duration supported by that workflow. Before submitting, verify the visible
mode, model, duration or storyboard total, ratio, attachment count, account,
and credit estimate. Submit once. If Agent mode pauses after reference-material
generation, continue in the same thread after checking the storyboard and
asset mapping.
