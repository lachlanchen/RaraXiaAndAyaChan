# 珠海暴雨里的救援箱

这是啦啦侠、阿芽酱、飒飒君和庄子机器人在珠海海边夏令营经历的一次暴雨救援。远处可见雨幕中的港珠澳大桥。山坡避雨屋断电，四位伙伴冒雨护送手电、药箱、毛巾和热姜茶。三台黑色机械掠夺者在湿滑栈道上抢夺救援箱，四人合作反击，最终把物资安全送到营员手中。故事紧张但温暖，结尾大家在避雨屋里喝热姜茶。

角色名称必须使用：啦啦侠、阿芽酱、飒飒君、庄子机器人。不要把他们描述成泰迪熊或陌生人。

视频中的中文对白如下，字幕校正应以实际音轨时间为准，不要用故事文字替换整段语音：

- 阿芽酱：“我们从旧栈道过去，那里离避雨屋最近。”
- 啦啦侠：“你看路，我护着箱子。”
- 啦啦侠：“药箱可以晃，姜茶不能洒！”
- 庄子：“手电、药箱、毛巾，一样没少。”
- 啦啦侠：“那热姜茶呢？”
- 阿芽酱：“先给最会挡雨的人。”
