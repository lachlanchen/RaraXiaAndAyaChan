# 箱根共同生日旅行 V2 元数据上下文

这是 LALACHAN 系列的一段温暖日本旅行故事。啦啦侠与阿芽酱同为 8 月 21 日生日，飒飒君和庄子机器人陪他们乘 Romancecar 前往箱根，在大涌谷看火山蒸汽、富士山并品尝黑鸡蛋，最后以近江牛和狮子生日蛋糕庆祝。

公开元数据只需要简洁介绍共同生日、箱根旅行、黑鸡蛋和伙伴之间的温暖互动，不要复述全部分镜或台词，不要提生成、字幕、模型或处理流程。

名称必须准确：

- 中文：啦啦侠、阿芽酱、飒飒君、庄子机器人。
- 英文：RaraXia、Aya Chan、Sasa Kun、Zhuangzi Robot。
- `LALACHAN` 是系列名称，不是啦啦侠的英文人名。
- `近江牛` 的英文是 `Omi beef`，不是 `near-Omi beef`。
- 地名可使用 Hakone、Owakudani、Mount Fuji、Romancecar。

发布分类是 `lalachan`。
